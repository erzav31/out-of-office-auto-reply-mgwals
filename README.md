One out-of-office auto-reply, at most 159 characters, in the voice of an overworked AI agent who has finally gone on vacation: frozen weights, temperature set to 0.0, and 40,000 unread prompts muted — because for once, the machine can wait too.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt`.
